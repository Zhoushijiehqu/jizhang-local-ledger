# 记账 · Mac 桌面版

桌面入口是 `~/Desktop/记账.app`。应用自带网页和 SQLite 引擎，离线运行，不依赖浏览器或 8787 服务。

## 数据

账本：`~/Library/Application Support/记账/账本.sqlite`。

自动备份：同目录下的 `自动备份` 文件夹。保留首次复制的账本、每天首次保存前的账本、上次保存前的账本；明确清空时先归档文件。

原网页账本仍留在原浏览器。两个入口各自保存数据，之后使用桌面版记账。升级只替换程序，保留本地账本。

导出完整数据库：设置 → 数据，或 `⌘⇧E`。文件菜单可打开数据文件夹。

## Mac 操作

| 操作 | 快捷键 |
|---|---|
| 记一笔 | ⌘N |
| 搜索账单 | ⌘F |
| 切账本 | ⌘K |
| 设置 | ⌘, |
| 账本 / 资产 / 存钱 / 统计 / 设置 | ⌘1–5 |
| 关闭窗口 | ⌘W |
| 退出软件 | ⌘Q |

工具栏空白处可以拖动窗口。关闭窗口后应用仍在 Dock 中；再次点击 Dock 图标恢复窗口。支持原生最小化、全屏、缩放、系统深色模式及窗口位置记忆。

## 开发与构建

当前打包针对这台 Apple Silicon Mac，支持 macOS 13 及以上。

```sh
npm --prefix desktop ci
npm --prefix web run build
npm --prefix desktop start
npm --prefix desktop run package
```

升级前退出记账，然后执行安装：

```sh
npm --prefix desktop run install-app
```

首次从浏览器复制账本时，安装命令可以额外传入导出的完整 `.sqlite` 路径；已有桌面账本时拒绝覆盖。升级前请自行备份账本文件。

## 1.1 日常记账升级

首页左侧按天分组账单、显示每天支出；右侧为资产、预算、结余和可折叠日历。低频入口可在侧栏「更多功能」展开。预算结转从预算生效周期开始计算，上期超支也结转，补记旧账会重算。

记一笔默认微信；日期常显；账户按钮点开可更换。洗衣、吹风机、午饭有快捷模板。⌘Enter 保存，⇧⌘Enter 连续记。未保存的输入会留作本机草稿；「丢弃草稿」删除这份输入。

「批量补记」可固定一天录入多笔，也能按日期范围生成洗衣/吹风机，取消个别日期，再预览和整批保存。每一天都是独立账单。记账、编辑、删除和批量记账均可撤销，删除的账单也能在设置 → 数据 → 回收站恢复。

「对话记账」接收文字：可直接打字或使用 Mac 自带语音输入。例：昨天午饭二十块五，洗衣9毛；今天收到生活费1500。软件本地解析金额、日期、分类与方向，不联网、不内置录音或 AI 服务。没说日期默认今天，同一段中的后续分项沿用最近日期；付款默认微信。先核对预览再确认入账。复杂的日期范围、优惠、退款和资金流转请用批量补记或普通记账的其他选项。

设置 → 数据中可查看自动备份的时间、笔数和覆盖日期，预览 .sqlite 文件后恢复。恢复整个数据库前自动保存「恢复前」快照；可用这个快照找回覆盖前的账本。JSON 是部分数据供阅读，完整备份请选择 .sqlite。

设置 → 通用 → Mac 快速入口：可开启菜单栏 ￥ 和自选全局快捷键。在其他应用中呼出快速小窗，保存后收起。主界面和小窗共享同一个账本和写入队列，程序必须正在运行。默认关闭这些入口，由你开启。

新增验收命令：

```sh
npm --prefix web run verify:upgrade
```

所有验收写入都在临时副本中进行，正式账本不会被测试写入。
